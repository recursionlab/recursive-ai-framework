## 🚨 Troubleshooting During Demo

### If Streamlit won't start:
```bash
streamlit run cognitive_workshop.py --server.port 8502
```

### If data files missing:
```bash
python3 setup.py
# Wait 10-15 seconds
streamlit run cognitive_workshop.py
```

### If browser doesn't open:
Navigate manually to: `http://localhost:8501`

### If visualization looks broken:
- Refresh page (Ctrl+R / Cmd+R)
- Check that extraction_outputs/ has all JSON files
- Verify networkx installed: `pip install networkx`
